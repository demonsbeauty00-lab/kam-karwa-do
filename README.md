# Kaam Karwa Do

## Project ko chalane ke commands

1. Node.js install hona chahiye (version 18 ya usse upar). Check karne ke liye:
   node -v

2. Project folder mein jaayein aur dependencies install karein:
   npm install

3. Development server chalayein:
   npm run dev

4. Browser mein kholein:
   http://localhost:3000

## Production build (jab app ko live karna ho)

   npm run build
   npm start
